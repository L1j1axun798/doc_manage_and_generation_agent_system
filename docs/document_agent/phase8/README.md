# Document Agent Phase 8

Phase 8 已在项目详情中增加“入场资料编制（四措两案）”页签，页面受前端
`VITE_DOCUMENT_AGENT_ENABLED` 开关控制，默认不显示。

页面流程：

1. 选择已批准模板和当前项目已有资料，不新增合同或敏感资料上传入口；
2. Agent 异步提取带来源的项目事实；
3. 用户确认、纠错或补充事实；
4. Agent 异步生成八章节初稿；
5. 用户逐章编辑、查看引用和校验问题、锁定或重新生成；
6. 项目负责人/系统管理员批准；
7. 导出 Word 到当前项目“技术方案”目录并使用现有下载接口。

前端对 `extracting`、`queued`、`generating` 每 2 秒轮询一次，任务结束或页面离开立即
停止。后端权限和状态机是最终控制，前端隐藏按钮不作为权限边界。页面固定提示本功能不
生成检测报告、实测结论或完工报告。
